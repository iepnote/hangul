# 🏡 한글 놀이터

특수교육 대상 학생을 위한 한글 학습 웹앱 모음 — 설치 없이 브라우저에서 바로 사용합니다.

| 앱 | 내용 |
|---|---|
| 🔤 자음모음과 놀아요 | 자음·모음 24자 + 자모별 예시 낱말 3개 |
| 📚 소리를 듣고 찾아요 | 받침 없는 낱말 32개(주제 4갈래) |
| 🃏 낱말과 놀아요 | 가나다 낱말 106개 + 낱말 완성 + 색칠하기 |
| 📌 받침과 놀아요 | 기본 받침 6개 최소대립쌍 |
| 🚂 낱말 기차 잇기 | 끝말잇기 기차(가·나 단계) + 라온식 낱말판(다 단계, 2인 가능) |

## 쓰는 법
1. 놀이터 홈에서 학생을 고르거나 ➕로 추가합니다(5개 앱에 한 번에 만들어져요).
2. 추천 단계로 바로 시작하거나 🎈 자유 모드로 아무 단계나 고를 수 있습니다.
3. 🧑‍🏫 학생 관리에서 학생별 진도를 한눈에 보고 사진·이름을 관리합니다.
4. 각 앱의 ✏️ 편집에서 낱말·그림을 학생에 맞게 바꿀 수 있습니다(↩️ 초기화로 복구).

기록은 **사용하는 기기의 브라우저에 저장**됩니다(기기마다 따로).
